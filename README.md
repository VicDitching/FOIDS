# File-Oriented Information Deletion System (FOIDS)
SE 300 Project

# DESCRIPTION
This application is designed to delete bulky, unnecessary files on your desktop. These include:
-Win11 Temp Files
-Browser Cache
-Windows Crash Dumps
-Windows Recycle Bin
-Application Cache
-Log Files
It is designed to keep all important files safe

# Dependencies
Windows 11
Python 4
This application will not work on any system other than Windows 11

# Installation
Download files at: https://github.com/VicDitching/FOIDS
Extract all files with the default Windows 11 settings

# Executing program
-Run foids.exe
-Select desired checkboxes 
-Press scan and wait for it to finish
-If the scan finished successfully, press delete
-Press reset if the application fails at any point
